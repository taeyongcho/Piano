# 🎹 피아노 연습실

[![CI](https://github.com/taeyongcho/Piano/actions/workflows/ci.yml/badge.svg)](https://github.com/taeyongcho/Piano/actions/workflows/ci.yml)

전자피아노를 USB로 컴퓨터에 연결해 놓고 쓰는 **웹 연습 프로그램**입니다.
브라우저에서 바로 열리고, 설치할 것도 만들 것도(빌드도) 없습니다.

전자피아노가 없어도 컴퓨터 자판이나 화면 건반으로 모든 연습을 그대로 해볼 수 있습니다.

## 빠르게 시작하기

```bash
npm start          # → http://localhost:5173
```

또는 파이썬만 있어도 됩니다.

```bash
python3 -m http.server 5173
```

브라우저에서 `http://localhost:5173` 을 열고 **[전자피아노 연결]** 을 누른 뒤,
브라우저가 물어보는 MIDI 접근 권한을 허용하세요.

> `file://` 로 직접 열면 Web MIDI 가 동작하지 않습니다. 반드시 위처럼 `localhost` 로 여세요.
> (`localhost` 와 `https` 만 보안 컨텍스트로 인정됩니다.)

## 전자피아노 연결

1. 피아노의 **USB to HOST** 단자와 컴퓨터를 USB 케이블로 연결합니다.
2. 대부분의 기종은 별도 드라이버 없이 바로 인식됩니다.
3. 페이지를 열고 **[전자피아노 연결]** → 권한 허용.
4. 상단에 장치 이름이 뜨면 준비 끝입니다. 여러 대가 잡히면 목록에서 고르면 됩니다.

**브라우저**: Web MIDI 를 지원하는 Chrome / Edge / Opera 를 권장합니다.
Safari · Firefox 에서는 MIDI 입력이 안 되지만, 컴퓨터 자판과 화면 건반으로는 그대로 쓸 수 있습니다.

서스테인 페달(CC64)도 인식해서 앱 소리에 반영합니다.

## 연습 모드

| 모드 | 무엇을 연습하나 |
| --- | --- |
| 🎹 **자유 연주** | 누른 음과 화음 이름을 실시간으로 알려줍니다. 자리바꿈(예: `C/E`)과 음정까지 표시합니다. |
| 🎼 **악보 읽기** | 오선보에 뜬 음을 건반에서 찾습니다. 큰보표/높은음/낮은음, 조성, 단음·3화음, 임시표 포함 여부를 고를 수 있습니다. |
| 🪜 **음계** | 14가지 음계를 한 음씩 순서대로. 옥타브 수·방향을 정하고, 끝나면 걸린 시간과 **박자 고르기** 점수를 보여줍니다. |
| 🎵 **화음** | 코드 기호를 보고 짚기, 그리고 `I–V–vi–IV` 같은 코드 진행 따라 치기. 자리바꿈 허용 여부를 고를 수 있습니다. |
| 💪 **핑거 연습** | 하농 1번 스타일, 5손가락, 분산화음, 트릴 패턴을 한 음씩 올려가며 반복합니다. |
| 👂 **청음** | 음정 따라 치기, 화음 종류 맞히기, 멜로디 따라 치기. |
| 📈 **기록** | 연속 연습 일수, 오늘/누적 연습 시간, 정확도, 최근 30일 그래프, 모드별 시간. |

메트로놈은 어느 모드에서나 화면 위쪽에 늘 떠 있습니다. 탭 템포로 빠르기를 잡을 수도 있습니다.

## 조작

| 키 | 기능 |
| --- | --- |
| `Z S X D C V G B H N J M` | 낮은 옥타브 (자판 연주) |
| `Q 2 W 3 E R 5 T 6 Y 7 U I` | 한 옥타브 위 |
| `-` / `+` | 자판 연주의 옥타브 이동 |
| `Space` | 메트로놈 시작 / 정지 |

화면 건반은 마우스나 터치로도 누를 수 있습니다.

## 개발

의존성이 하나도 없습니다. 순수 ES 모듈 + SVG + Web Audio 로만 되어 있습니다.

```bash
npm test           # 음악 이론·연습 진행기 단위 테스트
```

`main` 으로의 푸시와 모든 PR 에서 GitHub Actions 가 Node 20 · 22 로 단위 테스트를 돌리고,
단위 테스트가 불러오지 않는 브라우저 전용 모듈까지 `node --check` 로 문법을 확인합니다.

```
index.html          진입점
styles.css          전체 스타일
server.mjs          의존성 없는 정적 서버
src/
  main.js           앱 셸 — 상단 바, 메트로놈, 모드 전환, 건반
  theory.js         음이름·조표·음계·화음·화음 인식
  staff.js          오선보 SVG 렌더러
  keyboard.js       화면 건반 SVG
  midi.js           Web MIDI 입력 + 컴퓨터 자판 대체 입력
  audio.js          피아노 음색 신시사이저 + 메트로놈 클릭
  metronome.js      정확한 박 예약, 탭 템포
  sequence.js       음/화음을 순서대로 짚는 연습 진행기
  stats.js          연습 기록 (localStorage)
  modes/            연습 모드 7개
test/               단위 테스트
```

새 모드를 만들려면 `src/modes/` 에 `{ id, title, icon, hint, mount(root, ctx) }` 를 내보내는 파일을 추가하고
`src/main.js` 의 `MODES` 배열에 넣으면 됩니다. `mount` 가 함수를 돌려주면 모드를 떠날 때 정리 함수로 호출됩니다.

## 기록과 개인정보

연습 기록과 설정은 **브라우저의 localStorage 에만** 저장됩니다. 서버로 아무것도 보내지 않습니다.
기록을 지우려면 [기록] 탭의 *기록 모두 지우기* 를 누르세요.

오선보의 음자리표 기호는 Google Fonts 의 Noto Music 을 씁니다. 인터넷이 없으면 시스템 글꼴로 대체됩니다.
